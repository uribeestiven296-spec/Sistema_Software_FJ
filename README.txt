PROYECTO: SISTEMA INTEGRAL DE GESTIÓN - SOFTWARE FJ
Curso: Programación - UNAD

ARCHIVOS
- main.py: ejecuta la demostración de 14 operaciones.
- entidades.py: clase abstracta Entidad y clase Cliente.
- servicios.py: clase abstracta Servicio y tres servicios especializados.
- reservas.py: creación, confirmación, cancelación y procesamiento de reservas.
- sistema.py: administración de clientes, servicios y reservas mediante listas.
- excepciones.py: excepciones personalizadas.
- software_fj.log: se genera automáticamente al ejecutar el programa.

REQUISITOS: Python 3.8 o superior. No requiere librerías externas.

EJECUCIÓN
1. Extraiga la carpeta del ZIP.
2. Abra la carpeta Sistema_Software_FJ en Visual Studio Code.
3. Abra una terminal en esa carpeta.
4. Ejecute: python main.py

Los datos se mantienen en listas mientras el programa está en ejecución.
No se utiliza una base de datos.
